## What I did
- `apps/engine/drishti/agents/photo_evidence/`: `stamp.py` (the trial's GPS-stamp reader with its 3 date fixes; the
  year window is now relative instead of ending in 2026), `geo.py` (pure-Python point-in-district and km-outside on
  `reference/district_outlines.json`, PIN check on `reference/pin_district.json`, both from
  `data/build_geo_reference.py`), `fingerprint.py` (256-bit pHash; computing needs Pillow+SciPy, comparing needs
  nothing), `index.py` (every work's files, fingerprints and stamp spots), `agent.py`, `engine.py` (order 7, weight 0).
- Checks: same photo on another work (file or fingerprint) 0.50; same paper on another work unless it reads as a
  combined file 0.40; stamp >5 km outside the district 0.50; PIN of another district (note); photo stamped 7+ days
  before the recommendation 0.40; stamp after the data date (note); >1 year after completion (note); same spot same
  day as another work (note). A citizen's photo (`source: "citizen"`) goes through the same checks (demo).
- `data/build_evidence.py` now also stores per file: stamps (engine reader), fingerprint, text line count. Run it
  with `.venv-trial` (fingerprints need Pillow + SciPy).
- `batch.indexes()` builds the photo index; the API builds it from every work's evidence (reuse crosses districts).

## Decisions made (and why)
- A new recommendation is dated the data's snapshot ("today" for real data), so the sanction clock has not run.
- Amber = any engine question, including "missing work type" (worth fixing before sanction).

## Problems, traps, surprises
- Re-dating an old real work to "today" hides its earlier copy: the repeat score weighs time (gap 225 → 533 days,
  score 0.80 → 0.74 < 0.75). The demo therefore checks each work on its own arrival day, against earlier works only.

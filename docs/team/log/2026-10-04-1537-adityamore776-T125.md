## Problems, traps, surprises
- `npx next dev` leaves `next-server` running when only npx is stopped; a second dev server in the same folder then
  never comes up. Stop the process group.
- `pkill -f <pattern>` also matches the shell running it when the pattern is in the command line.
- The video tests need OpenCV 4.x (OpenCV 5 has no `CascadeClassifier`; face blurring fails closed there).

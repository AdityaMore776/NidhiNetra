## Decisions made (and why)
- System font stack instead of Google Fonts: removes a build-time network dependency (air-gap/offline friendly) and is faster; the brief lists `system-ui` as acceptable.
- New Districts/Reports/Settings pages use only existing endpoints (`/dashboard/summary`, `/dashboard/districts`, `/dashboard/offices`, `/me`) so nothing is fabricated and role scoping is preserved by the backend.

## Problems, traps, surprises
- The repo's ESLint enforces `react-hooks/set-state-in-effect`; the fetch-in-effect pattern had to set state only inside async callbacks (handled by `lib/useFetch.ts`).
- Tailwind v4 `before:`/`after:` need explicit content; replaced pseudo-element accents in MetricBlock with a real element.
- Sandbox has no network, so the production build cannot fetch Google Fonts (another reason for the system-font switch).

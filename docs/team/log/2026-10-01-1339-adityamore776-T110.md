## What I did
- Owner's 12 → 8 merge (T051): Document (B4) and Contractor Network (C3) read the same certificates, so they are one
  engine, `apps/engine/drishti/agents/paperwork/` (registered "Paperwork", order 6, weight 0 = shown, not counted).
- `reader.py`: the trial's UC parser (`data/trial/document_trial.py`) ported as pure functions over OCR pages; also
  reads every payment and the certification page's boxes. Never returns the vendor's name or bank details.
- `agent.py`: checks P1 sanction late (graded, election pauses left out, same clock as Compliance R01), P2 sanction
  before recommendation, P3 more paid on paper than the portal (less = instalment note), P4 other works' papers,
  P5 "in progress" on paper (note), P6 blank certification (note), papers of several works (note), C1 vendor-code
  concentration (fact; a small note only next to another finding).
- `vendors.py`: vendor-code shares per district, built from the works given (batch: all; API: the district).
- `data/build_evidence.py` → `data/build/evidence_facts.parquet` → table `evidence_facts` (migration 009): derived
  facts only. `batch.py` joins it into each work (`work["evidence"]`) and builds the vendor index with the
  duplicate index (`indexes()`); `data/common.py` does the same locally.

  uses any own certificate with a date. The late and before counts are unchanged.

## Decisions made (and why)
- **Claims live in GitHub Issues, specs in TASKS.md, history in one-file-per-session logs.** Assigning an
  issue is atomic and visible to everyone; a shared progress file would conflict on every PR.
- **Every PR must add a log entry** (enforced by CI) so no session's knowledge is lost.
- **T100 (checker registry) goes first:** the orchestrator/fusion hard-code 4 old slots; without T100,
  parallel checker work would conflict on the same lines.
- **Data travels as a private zip in Google Drive**, because the repo is public and the evidence carries
  names and bank details.
- Evidence photos are not shown on the site (T305) unless the owner decides otherwise.

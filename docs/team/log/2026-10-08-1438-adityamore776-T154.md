## Problems, traps, surprises
- **Git Bash path mangling:** `modal volume put ... /gov/...` uploaded to `C:/Program Files/Git/gov/...`. Use
  `MSYS_NO_PATHCONV=1`. The misplaced copy under `/C:` was deleted by the owner (8 Oct).
- **The Modal CLI crashes printing ✓ on the Windows console** ("charmap codec"). Set `PYTHONIOENCODING=utf-8`. The
  upload itself had worked.
- `modal volume put` of a big folder can end part-way. Compare the folder lists (`v.listdir`) and put only the missing
  ones.
- The A100 `score` had a 1 h limit, which a 915-item run would have hit. Scoring now saves to the volume every 25
  answers and resumes.
- The timelapse hindsight teacher counts season, snow, captions and adverts as progress: only 1 of 41 timelapse
  "work added" labels was right. **This also bears on T146 (PR #120).**
- What stays wrong on the probe is all "an empty plot, then a close-up of a finished building elsewhere". Real
  building progress looks the same. Photos alone cannot separate them: the GPS tag or a shared landmark must.
- Windows Git Bash: `tail -1` fails inside some scripts. Use `tail -n 1`.

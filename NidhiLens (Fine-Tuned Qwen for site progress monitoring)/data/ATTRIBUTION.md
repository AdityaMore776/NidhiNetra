# Where the photos come from

- **GeoMGNREGA** (images/gov/mgnrega/photos/<asset id>/): the stage photos (1 before, 2 during, 3 after) that Indian MGNREGA works publish on ISRO's public Bhuvan portal (bhuvan-app2.nrsc.gov.in/mgnrega). Fetched at one request every 1.5 s. The asset id is Bhuvan's.

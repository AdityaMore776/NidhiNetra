# NidhiNetra web

Next.js 16 (App Router, React 19), Tailwind CSS 4, shadcn/ui (Radix, "nova" preset) with Kokonut UI components,
Recharts 3 for charts, MapLibre 6 (3D globe) on official LGD outlines, three.js / React Three Fiber for the 3D
scenes, Motion for component and scroll animation, GSAP for the 3D timelines, Lenis for smooth scrolling.

| Page | Shows |
|---|---|
| `/login` | sign in (Supabase email), with the 3D emblem and the story of how NidhiNetra works |
| `/` | dashboard: figures, the 3D review funnel, the 3D district globe, engine findings, risk mix, states, districts, money by state, offices, top of the queue |
| `/queue` | works needing review (High + Critical), highest priority first; `?band=` and `?page=` in the address |
| `/works` | search every work; `?q=`, `?type=`, `?band=`, `?district=` in the address |
| `/work?id=…` | one work: the score gauge and its reasons (English / हिंदी), every engine's answer, validation notes |
| `/presanction` | check a recommendation before sanction: Green, Amber or Red with reasons |
| `/how-it-works` | the pipeline and the engines |
| `/explain` | the Visualization Engine: one work through six animated steps (no sign-in) |

```bash
npm ci
npm run dev        # http://localhost:3000 — set NEXT_PUBLIC_DEV_ROLE for dev mode without login
```

## Where things live

| | |
|---|---|
| Design tokens (brand, engine and band colours, type) | `src/app/globals.css` |
| Fonts (Geist, Geist Mono, Instrument Serif, Noto Sans Devanagari) | `src/app/layout.tsx` |
| App shell: sidebar, top bar, Ctrl+K search | `src/components/shell/` |
| NidhiNetra building blocks: badges, work table, page headers, stat tiles | `src/components/nn/` |
| Charts | `src/components/charts/DashboardCharts.tsx` |
| 3D globe | `src/components/map/IndiaGlobe.tsx` |
| 3D scenes (emblem, review funnel) | `src/components/three/` |
| Scroll reveals, count-up, smooth scroll | `src/components/motion/` |
| shadcn/ui primitives (generated: `npx shadcn@latest add <name>`) | `src/components/ui/` |
| Kokonut UI components, adapted to the brand (`npx shadcn@latest add @kokonutui/<name>`) | `src/components/kokonutui/` |
| Engine client, shared GET cache | `src/lib/api.ts`, `src/lib/cache.ts` |
| The emblem: logo and icons; 3D model | `public/brand/`, `src/app/icon.png`; `public/models/nidhinetra-emblem.glb` |
| The 3D model's Blender source | `design/nidhinetra-emblem.blend` (scene "NidhiNetra"; export glTF with meshopt) |

Colour rules: the eight engine colours are a validated categorical palette, in `AGENT_ORDER`; never reorder or
cycle them. Band colours (Low / Medium / High / Critical) are status colours and always appear with their word.

Setup and env vars: [`docs/SETUP.md`](../../docs/SETUP.md).

*`AGENTS.md` / `CLAUDE.md` in this folder are coding-assistant notes generated by Next.js — the engines are
documented in [`docs/AGENT-CATALOG.md`](../../docs/AGENT-CATALOG.md).*

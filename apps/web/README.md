# DRISHTI web

Next.js 16 (App Router, React 19), Tailwind CSS 4, MapLibre 6 on official LGD outlines.

| Page | Shows |
|---|---|
| `/login` | Supabase email login |
| `/` | dashboard: totals, bands, money at stake, India district map, offices with record problems |
| `/queue` | works needing review (Medium/High), highest priority first |
| `/works` | search every work by text, district, type, band |
| `/work?id=…` | one work: the agent cards, the score breakdown, validation notes |
| `/how-it-works` | the pipeline explained in the app |

```bash
npm ci
npm run dev        # http://localhost:3000 — set NEXT_PUBLIC_DEV_ROLE for dev mode without login
```

Key files: `src/lib/api.ts` (engine client), `src/components/IndiaMap.tsx`, `AgentCard.tsx`, `FusionPanel.tsx`.
Setup and env vars: [`docs/SETUP.md`](../../docs/SETUP.md).

*`AGENTS.md` / `CLAUDE.md` in this folder are coding-assistant notes generated by Next.js — the DRISHTI
agents are documented in [`docs/AGENTS.md`](../../docs/AGENTS.md).*
